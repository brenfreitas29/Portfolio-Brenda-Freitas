# Brenda Studio Portfolio

Original portfolio implementation inspired by contemporary creative-tech studio patterns:
large editorial typography, full-screen statements, motion, product showcases, metrics and strong color transitions.

It does **not** copy Wishlabs assets, text, or pixel-identical layouts.

## Run

```bash
npm install
npm run dev
```

Open the local URL shown by Next.js.

## Build

```bash
npm run build
npm start
```
